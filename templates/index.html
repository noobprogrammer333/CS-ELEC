How the System Works

  1. User enters text or records voice using the microphone.
  2. JavaScript sends the input to the Flask backend.
  3. The NLP module tokenizes, analyzes sentiment, extracts keywords, and classifies text.
  4. The chatbot response is generated from intent, sentiment, and keywords.
  5. The conversation and NLP results are saved to the database.
  6. The response is shown on screen and can be spoken aloud.
